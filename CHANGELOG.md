### 0.2.0 highlights: everything before the first release (milestones M0–M4)

0.2.0 is the first numbered release. It bundles the work of the first five milestones:

- **M0 Foundations**: tests (vitest, supertest), lint and format checks, CI on GitHub-hosted runners, contributor
  docs, a VitePress documentation site.
- **M1 Secure by default**: read-only unless an admin token or a trusted forward-auth header allows editing;
  allow-listed API responses (no env vars, mounts or secret-looking labels); request validation, security headers
  and rate limiting; a socket-proxy example.
- **M2 Discovery v2**: the Traefik API as a discovery source (also for services outside Docker), exposure badges
  (public, SSO, private) from Traefik middlewares, and HTTP health checks per service.
- **M3 Knowledge base and icons**: one YAML file per service (200+ services), whole-repository image matching,
  dashboard-icons from a CDN, a self-hosted mirror or off, and a list of unrecognised images for editors.
- **M4 UX**: search (`/`, Enter opens the first result, `?q=` links), keyboard navigation, grouping by category,
  stack or host with collapsible groups, one status per card, and a layout for phones and tablets.

Release engineering (this release): numbered versions with this changelog, the version in the UI footer and in
`/api/health`, multi-arch images (`linux/amd64`, `linux/arm64`), an image vulnerability scan, SBOMs and provenance
attestations, and automated dependency updates.
